# 脉塔智能电机选型系统

面向脉塔（MyActuator）行星模组、谐波模组、摆线模组、中空直驱与无框电机的在线选型工具。

**在线地址**：https://swaggyp04.github.io/MYACTUATOR--selection/

---

## 功能

| 模块 | 说明 |
|---|---|
| 手动选型 | 按额定/峰值扭矩、模组类型、通讯、电压、尺寸、转速、功率筛选 |
| 选型计算 | 由负载、力臂、目标转速、加速时间、安全系数计算所需扭矩与功率 |
| 文档导入选型 | 从 PDF / 图片中提取参数并匹配型号 |
| 产品库 | 71 款模组的完整规格，含电气参数与堵转数据 |
| 拼装机器人 | 三栏配置界面：关节槽位 / 执行器库 / 实时汇总（重量、电流、功率、电源建议） |
| 智能问答 | 本地知识库（FAQ + 产品参数 + 选型建议），无需联网 |
| 方案推荐 | 按人形 / 机械臂 / 四足 / 夹爪构型生成整套驱动方案与 BOM |
| 支持中心 | 关节选型、工况校核、占空比校核、故障码、排障向导、参数说明、教程 |
| 常见问题 | 可折叠 FAQ |

## 目录结构

```
index.html            主页面
admin.html            管理后台（在线编辑 FAQ）
assembly-view.html    3D 装配演示（iframe 单文件）
css/style.css         样式
js/data.js            产品数据（PRODUCTS）
js/app.js             核心逻辑：筛选、推荐、问答、方案生成
js/sizing_build.js    选型计算 + 拼装机器人
js/support_data.js    故障码 / 排障向导 / 参数说明 / 教程数据
data/faq.json         常见问题（可在管理后台在线编辑）
images/               产品与示意图
lib/                  第三方库（SheetJS / Mammoth / Tesseract）
```

## 更新 FAQ

1. 打开 `admin.html`
2. 输入访问密码，用有仓库写权限的 GitHub 账号授权
3. 编辑后保存，`data/faq.json` 会自动更新并触发网站重新部署

## 数据来源

2026 年 6 月产品手册与官方 datasheet。抱闸为定制选项，标准品为无抱闸版本。

## 说明

选型结果为**初筛**：算法按最不利姿态估算扭矩与转速，用于快速比对方向，最终配置请与脉塔确认。
