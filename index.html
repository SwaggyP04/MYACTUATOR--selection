📐 计算公式
重力扭矩：Tg = m × g × L
角加速度：α = 2πn / (60t)
加速扭矩：Taccel = J × α
峰值扭矩：Tpeak = (Tg + Taccel) × 安全系数
额定扭矩：Trated = Tg / 效率 × 安全系数

循环工况

电机可以短时超过额定扭矩，只要整个循环的均方根（RMS）扭矩不超过额定值。 按实际工作循环填写各段的扭矩与时长，停留/空载段扭矩填 0。

循环分段
RMS τ = √( Σ τᵢ²·tᵢ / Σ tᵢ )
判定：RMS ≤ 额定扭矩，且每一段 ≤ 峰值扭矩。
