如何获取访问令牌（只需做一次）：
  1. 打开 github.com/settings/tokens?type=beta
  2. 点 Generate new token
  3. Token name：随便填，如 faq-admin
  4. Expiration：建议 90 天
  5. Repository access：选 Only select repositories → 勾选 MYACTUATOR--selection
  6. Permissions → 展开 Repository permissions → 找到 Contents → 设为 Read and write
  7. 点 Generate token，复制那串 github_pat_...

⚠ 只有被加为仓库 Collaborator 的账号，令牌才有写权限。其他人即使拿到令牌也会被 GitHub 拒绝。
令牌只保存在本机浏览器，不会上传到任何服务器
